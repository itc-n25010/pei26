# pei26

シンプルな Python プロジェクトの雛形です。  
学習用や小さなサンプル開発の出発点として使えるよう、最小限の構成でまとめています。

## 概要

このプロジェクトには、Python の基本動作を確認できるサンプルコードが含まれています。  
`hello.py` と `main.py` を用意しており、簡単な実行確認から始められます。

## ファイル構成

- `hello.py` : 最小限の "Hello, World!" サンプル
- `main.py` : 実行用のエントリーポイント
- `pyproject.toml` : Python プロジェクト設定
- `README.md` : この説明書

## 実行方法

仮想環境を有効化して、次のコマンドで実行できます。

```bash
source .venv/bin/activate
python hello.py
python main.py
```

## 使い方の例

1. 依存関係の確認
2. サンプルコードの動作確認
3. 必要に応じて機能を追加して開発を進める

## 目的

- Python の基本を理解する
- 小規模なプロジェクトの雛形を持つ
- 実行確認しやすい構成にする

## 補足

このリポジトリは教育用・試作用の最小構成を意識しており、今後機能を拡張してアプリケーションとして育てていくことを想定しています。
