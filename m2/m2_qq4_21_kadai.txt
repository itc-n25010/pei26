pythonの演算子について
１：算術演算子
+	足し算      [5 + 3]	8
-	引き算	    [5 - 3]	2
*	掛け算	    [5 * 3]	15
/	割り算	    [5 / 2]	2.5
//	整数除算（切り捨て）   
                [5 // 2]	2
%	割り算の余り[5 % 2]	1
**	べき乗      [5 ** 2]	25

２：比較演算子
==	等しい	    [5 == 5]	True
!=	等しくない	[5 != 3]	True
>	より大きい	[5 > 3]	    True
<	より小さい	[5 < 3]	    False
>=	以上	    [5 >= 5]	True
<=	以下	    [3 <= 5]	True

３：論理演算子
and     両方の条件がTrue
[5 > 3 and 4 > 2]   True
or      どちらか一方でもTrue
[5 < 3 or 4 > 2]    True
not     条件の結果を反転
[not 5 > 3]     False

４：その他
=	代入	[a = 5]	aに5を代入
+=	加算して代入	[a += 3]	aに3を足す
-=	減算して代入	[a -= 3]	aから3を引く
*=	乗算して代入	[a *= 3]	aに3を掛ける
/=	除算して代入	[a /= 2]	aを2で割る
in	要素が含まれるか確認
3 in [1,2,3]	True
not in	要素が含まれないか確認
5 not in [1,2,3]	True

５：演算子の優先順位
1	()	括弧内の計算
2	**	べき乗
3	+x、-x	正負の符号
4	*、/、//、%	掛け算・割り算など
5	+、-	足し算・引き算
6	<、>、==、!=、<=、>=	比較演算
7	not	論理否定
8	and	論理積
9	or	論理和
10	=、+=、-= など	代入（右から左）
※ 同じ優先順位の演算子は、多くの場合左から右に計算する。
